# 刷机与升级说明 — CS75PLUS 2020款（1.5T / 2.0T）(S311-WT)

本文对应镜像包：`CoagentUpgrade` 全套（OS + MCU + TBOX + 语音数据）。

---

## 0. 刷机前必读

| 检查项 | 要求 |
|---|---|
| 车型 | 长安 CS75PLUS **2020 款 1.5T / 2.0T**（同平台，固件通用），车机平台 **S311-WT** |
| 确认平台 | 车机「设置 → 关于 / 系统信息」中 OS 版本以 `OS_S311-WT-V8` 开头 |
| 电量 | 车辆电瓶状态正常，**全程接外接充电器或保持通电**，禁止点火启动 |
| U 盘 | 8GB 以上，**FAT32**，根目录无其他升级文件夹 |
| 时间 | 全程约 10~20 分钟，期间绝对不能断电或拔 U 盘 |

> ❗ 平台不符、包损坏、中途断电均可能导致车机无法启动。若不确定，请先联系 4S 店确认平台再刷。
> ❗ 本包为**原厂完整包**，升级程序自身会校验 `MD5.txt`；校验失败会自动中止，不会写入固件。

## 1. 准备 U 盘目录结构

把整个 `CoagentUpgrade` 文件夹（**不是**里面的子文件夹）复制到 U 盘根目录：

```
U盘根目录/
└── CoagentUpgrade/
    ├── Os/
    │   ├── update.zip                 ← 从 Release 下载
    │   ├── MD5.txt                    ← 原厂自带，内容 e4751da5f1f7ec31f85332dce422573b
    │   └── os_versions.txt            ← OS_S311-WT-V8_V00.98.00-191227
    ├── Mcu/
    │   ├── McuAppUpdate.img           ← 从 Release 下载
    │   ├── MD5.txt                    ← 内容 6007ec4ddd5d398c10ae9bdb66f9608d
    │   └── mcu_versions.txt           ← MC_V8_S311_V0.68C_191220
    ├── Tbox/
    │   ├── tbox-os.tar.gz             ← 从 Release 下载
    │   ├── tbox-bsp.tar.gz            ← 从 Release 下载
    │   ├── tbox-app.tar.gz            ← 从 Release 下载
    │   ├── md5.txt
    │   └── tbox_version.txt
    └── SoundData/
        ├── wecarspeech.zip            ← 从 Release 下载
        ├── md5.txt
        ├── wecarspeechMd5
        └── sound_data_versions.txt
```

**最低可用组合**：只放 `Os/` 也能完成系统升级（`update.zip` + `MD5.txt` + `os_versions.txt`）。
需要同时更新 MCU / TBOX / 语音时，再补上对应目录。

复制完成后建议在电脑上先自查一遍：

```bash
md5sum -c MD5SUMS.txt        # 在放有 6 个镜像的目录执行
```

## 2. 执行升级

1. 车辆熄火，档位 P，**不踩刹车**按一下启动键 → ACC ON（仪表点亮、车机开机）；
2. 把 U 盘插入车机 USB 口（扶手箱内 / 前排 USB 均可，优先使用数据口）；
3. 车机通常在 **10~60 秒内**自动弹出「检测到升级包，是否升级」提示；
4. 点击**确定 / 升级**，之后屏幕会显示进度条（OS 包阶段最慢，可达 10 分钟以上）；
5. 升级过程中车机可能多次自动重启，**不要拔 U 盘**；
6. 出现「升级成功」或回到桌面后，拔出 U 盘，进入「设置 → 关于」确认版本号。

### 未自动弹窗怎么办

- 换一个 USB 口重插，等待 1 分钟；
- 确认 U 盘是 FAT32（NTFS/exFAT 部分车机不识别）；
- 确认根目录下就是 `CoagentUpgrade`（大小写敏感，不要多套一层文件夹）；
- 部分版本需在**工程模式**里手动触发升级（见下节）。

## 3. 工程模式（备用途径）

> ⚠️ 待确认：不同批次车机的工程模式入口/密码不一致，请以实车为准。

常见入口（按顺序尝试）：

1. 「设置 → 系统 → 关于本机」连点版本号 5~7 次；
2. 「设置 → 系统」页面长按某信息项 3 秒；
3. 车机拨号/计算器类隐藏入口输入工厂密码（本仓库未收录具体密码，避免误操作）。

进入工程模式后，找到 `升级 / OTA / Upgrade` 菜单 → 选择 U 盘 → 指定 `CoagentUpgrade` 目录 → 执行。

## 4. 常见问题排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示「升级包校验失败 / MD5 错误」 | 下载损坏或传输中断 | 重新下载并核对 MD5 |
| 进度条卡住不动超过 30 分钟 | U 盘读写异常 | 保持通电，换 U 盘重刷 |
| 升级后卡在开机 LOGO | OS 写入异常 | 重新插 U 盘，等待二次自动升级；无效则需服务站刷写 |
| 升级后无 4G / 无信号 | TBOX 版本不匹配 | 重新刷 `Tbox/` 三个包（os → bsp → app 顺序） |
| 语音助手异常 | 语音数据包未更新 | 补刷 `SoundData/wecarspeech.zip` |
| 屏幕无显示但能听到声音 | 显示/背光 MCU 状态异常 | 断电 5 分钟后重新上电；仍异常需服务站处理 |

---

## 5. 版本回滚

原厂包**不支持直接回滚**（升级程序只接受更高或相同版本号）。若必须回退旧版本，需要：

- 服务站使用专用工具 + 授权固件；
- 或经工程模式强制写入（风险极高，不建议自行操作）。
